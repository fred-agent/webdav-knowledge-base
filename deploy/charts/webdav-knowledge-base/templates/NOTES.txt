Fred accepts its declaration only from a listed client: add this entry to
`knowledge_bases.publishers` in the Fred chart's values
(applications.control-plane-backend.configuration), then restart the Control Plane:

    - client_id: {{ $kb.configuration.security.m2m.client_id }}
      prefix: {{ $kb.configuration.knowledge_base.prefix }}

The `publish` Job then declares it after each install, upgrade and rollback, and a
platform admin enables it for teams (Admin > Features > Knowledge Bases).

  kubectl -n {{ .Release.Namespace }} logs deployment/{{ $fullname }}

Declaration:
  kubectl -n {{ .Release.Namespace }} logs job/{{ $fullname }}-publish
